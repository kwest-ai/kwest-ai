# Kwest AI - Restaurant Analytics Landing Page

A modern, high-converting landing page for Kwest AI's AI-powered restaurant analytics platform. Built with Jekyll for GitHub Pages deployment.

## Features

- **Hero Section** - Compelling headline with live guest analytics dashboard visualization
- **Problem/Solution** - Side-by-side comparison of scattered vs. unified data
- **Stats** - Key metrics showing impact (restaurants, guest profiles, revenue growth, ROI)
- **Advantages** - Three core value props (Operational Efficiency, Customer Intelligence, Revenue Maximization)
- **Testimonials** - Real restaurant owner quotes with specific metrics
- **CTA** - Call-to-action with free consultation signup
- **Contact Modal** - Inline form for lead capture
- **Responsive Design** - Mobile-optimized with glassmorphism UI

## Quick Start

### Local Development

```bash
bundle install
bundle exec jekyll serve --livereload
```

Visit `http://127.0.0.1:4000` to preview.

### Deploy to GitHub Pages

```bash
git add .
git commit -m "Kwest AI Jekyll site"
git push origin master
```

GitHub Pages auto-builds from `master` branch.

## Customization

Edit CSS variables in `assets/css/main.css` for colors and theming. Wire contact form in `index.html` to your email service (Resend, Formspree, etc.).
